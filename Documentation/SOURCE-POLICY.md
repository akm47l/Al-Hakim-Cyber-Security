# سياسة المصادر

الأولوية للموقع الرسمي، وتوثيق المطوّر، ومستودع المصدر الأصلي، وصفحة التنزيل الرسمية. لا تُستبدل هذه بمواقع إعادة رفع الملفات. روابط البحث أو الفهارس (مثل GitHub Topics) هي نقطة اكتشاف فقط وليست إثباتاً لترخيص مشروع أو سلامته. يوضح `verification_status` ما إذا كانت بيانات الرابط قد فُحصت مباشرة.

# Al-Hakim Cyber Security

قاعدة معرفية تقنية عربية قابلة للتوسع للأدوات والمشاريع والمصادر الرسمية في الأمن السيبراني. جُمعت العناصر المذكورة في المواصفات مع سجلّات مستقلة وملفات JSON قابلة للمعالجة آلياً؛ لا تُرفع نسخ تنفيذية للأدوات ولا تُشغّل اختبارات على أهداف خارجية.

> **النطاق:** التعلّم، الدفاع، التحليل، والاختبار المصرّح به فقط. لا تستخدم أي أداة إلا على أنظمة أو بيانات تملكها أو لديك تفويض واضح لاختبارها. أدوات التحليل الديناميكي للبرمجيات الخبيثة يجب تشغيلها داخل بيئة معزولة وغير متصلة بالشبكات الحساسة.

## الحالة الحالية

- السجلات الأولية: **63**.
- الأقسام: **15**.
- مصادر وروابط مفهرسة: **190** (لم يكتمل فحص كل رابط بعد).
- الحقول التي لا يتوافر لها دليل رسمي موثوق تبقى «غير متوفر» أو «بانتظار التحقق»؛ لا تُستنتج تراخيص أو متطلبات أو إصدارات بالتخمين.
- لا يعني وجود سجل هنا أن الأداة مجانية أو مفتوحة المصدر. حالة الترخيص والسعر لا تُعتمد إلا بعد التحقق من المصدر الرسمي والترخيص upstream.

## التحديث والتحقق

شغّل فاحص الكتالوج محلياً: `python3 Scripts/audit_catalog.py --save`. ينشئ كل تشغيل لقطة مستقلة داخل `Updates/history/` ولا يستبدل اللقطات السابقة. يراجع سير GitHub Actions الروابط والبيانات الوصفية أسبوعياً وعند التشغيل اليدوي؛ ولا يشغّل الأدوات الأمنية نفسها.

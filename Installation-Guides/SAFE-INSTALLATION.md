# التثبيت الآمن

1. ابدأ دائماً بصفحة التنزيل أو تعليمات التثبيت الرسمية المرتبطة في سجل الأداة.
2. تحقق من التوقيع أو checksum المنشور رسمياً إذا كان المشروع يوفره، وقارن النتيجة قبل التثبيت.
3. راجع الترخيص والتبعيات والمتطلبات قبل التنفيذ، واستخدم حساباً محدود الصلاحيات.
4. ثبّت أدوات التحليل الحساسة في VM أو مختبر مخصص. لا تفتح عيّنات مجهولة على جهازك الأساسي.
5. لا تنسخ أوامر من صفحات غير رسمية، ولا تشغّل ماسحاً على شبكة عامة أو هدف غير مصرح به.
6. لا يتضمن هذا المستودع نسخاً من البرامج أو أوامر موحدة لأنظمة مختلفة؛ اتبع دليل المشروع الأصلي.
